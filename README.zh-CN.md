# 电脑急诊

[English](README.md)

电脑和手机连着同一个 Wi-Fi，却都打不开网页？先别重置电脑。电脑急诊根据你选的现象，告诉你下一步先查哪里。它也能帮你检查按键、观察屏幕坏点、梳理异常重启线索。

**v0.7 离线浏览器预览。** 下载完整目录（GitHub 上点 **Code → Download ZIP**），解压后用浏览器打开 `index.html`，默认显示英文，点击「简体中文」切换；也可以直接打开 `zh/index.html`。不用安装，不用联网。

| 工具 | 能做什么 |
| --- | --- |
| 断网排查 | 从多个设备同时失败、单个网站不通、公共 Wi-Fi 登录等现象中缩小排查范围。 |
| 键盘测试 | 在测试页显示浏览器收到的按键。没亮不等于硬件坏了。 |
| 屏幕纯色检查 | 手动切换六种颜色，用肉眼观察固定亮点、暗点和色点。 |
| 卡死与重启 | 用演示样例或兼容的匿名摘要查看时间线，不把异常重启当成故障原因。 |

想试用导入功能？用[合成样例](docs/examples/README.md#简体中文)即可，不需要本机日志。

Linux 用户可以使用浏览器里的网络、键盘和屏幕工具，详见 [Linux 排查指南](docs/linux.md#简体中文)。重启工具可以看演示，但只接受 Windows 格式摘要，不读取 Linux 日志。

这一版不包含 Windows 自动采集脚本或 EXE，不会自动修改设置，也不会上传诊断结果。

最新一轮 [Edge 离线自动测试](https://github.com/liugedragon/computer-clinic/actions/runs/46113169840)在 GitHub 托管的 Windows Server 2025 和 Ubuntu 24.04 上通过，覆盖英文和简体中文。两边都验证了样例导入、模拟按键、六种纯色渲染，以及未确认全屏时的提示。Ubuntu 还验证了原生全屏和退出后的焦点恢复；Windows 测试只进入了浏览器窗口模式。这不代表 Windows 11 实机、实体硬件或真实日志通过。实机待测项见 [Windows 11 手动检查清单](docs/windows-checklist.md#简体中文)。

网络工具的中英文页面也通过了 Debian 13.7 上的 Playwright Firefox 153.0 离线测试，覆盖浅色和深色样式、选择症状、导入样例、粘贴有冲突的摘要和清空结果。本次未测 Linux 发行版自带的 Firefox 或其他工具。
