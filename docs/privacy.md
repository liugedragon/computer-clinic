# Diagnostic data and privacy

Computer Clinic can run offline from a fully extracted folder. It does not send troubleshooting answers, key marks, display observations, or imported summaries to an external service. It does not save the results between page loads or change operating-system settings.

- **Network:** Manual answers, examples, and compatible anonymous summaries. The tool does not run ping, DNS, or internet probes.
- **Keyboard:** Only the browser events delivered while the test is active and focused. The page identifies supported key positions, not composed text. Do not type passwords in the test area.
- **Display:** Optional positions you mark yourself. It does not read the screen, take photos, or record screenshots.
- **Restarts:** Built-in examples or the compatible summary you explicitly paste or select. Do not provide raw Windows logs or crash dumps.

You can clear data in the relevant tool, or close its page. Please use synthetic examples in public bug reports. Browser behavior outside the tool, such as extensions or downloaded files, is outside this project's control.
